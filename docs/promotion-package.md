## 2. Three campaign concepts

### Campaign A — "Cartoon Your Day" (UGC challenge)

- **Premise:** people post an ordinary photo (commute, desk, pet, dinner) and ask the
  community to cartoon it; the best results get reposted.
- **Mechanics:** daily prompt in the chat → members run it through the tool → post with
  `#CartoonYourDay` and tag `@CARTOON_SOL` → weekly round-up thread of the top 5.
- **Why it fits:** the product is a photo tool, so the input is free and infinite; it also
  produces the exact asset type the gallery needs.
- **Assets needed:** one prompt-of-the-day image, one round-up template.
- **Honest KPI:** number of submissions and number of participants — both countable in a
  single search. Do not track or promise reach.

### Campaign B — "Panel by Panel" (serial storytelling)

- **Premise:** the site's cast (the rabbits in the meadow) anchor a short weekly story told
  in generated frames — a recurring character the audience recognises.
- **Mechanics:** one 3–4 frame story per week, posted as a thread; each frame generated with
  the product; the community votes on next week's ending in a reply poll.
- **Why it fits:** serials create return visits and give the account a reason to post when
  there is no product news.
- **Assets needed:** a character sheet from the official key art (do **not** invent names or
  lore — use the art as-is until the project names them), one thread template.
- **Honest KPI:** completion rate per thread (replies on frame 1 vs. frame 3).

### Campaign C — "Clip Drop Friday" (weekly showcase)

- **Premise:** a single new example clip every Friday, posted at a fixed time, with the
  prompt that produced it attached.
- **Mechanics:** collect clips during the week from Campaign A submissions or the team's own
  runs → post one on Friday with the exact prompt → invite quote-RTs of the clip itself.
- **Why it fits:** consistency beats intensity for a dormant-then-active account; a fixed
  appointment is the cheapest growth lever available.
- **Assets needed:** clip inbox in the chat, one "Clip Drop" cover image.
- **Honest KPI:** how many quote-RTs the clip gets; anything else is noise.

## 3. Three shareable-content ideas (static pages)

These are built as real pages by `npm run sharepages`, so each has a stable URL and its own
Open Graph preview — paste the URL anywhere and it renders a card.

1. **Prompt card** — `/share/prompt-card.html`
   The site's official sample prompt (*"A young couple went on a romantic walk in the park"*)
   on a branded card with a one-tap copy button. Share it so people start from a good prompt
   instead of an empty box.
2. **Gallery pick** — `/share/gallery-pick.html`
   One real timeline artwork, credited and linked back to its original X post, framed as
   "made with CARTOON AI". Credit is the whole point: it makes the share safe.
3. **Quick facts card** — `/share/quick-facts.html`
   What $CARTOON is, the official CA, and only verified links — no price, no market cap,
   no forecasts. Meant to be dropped into reply threads and group chats.

Run `npm run og` afterwards to place the matching preview images in `public/og/`.
